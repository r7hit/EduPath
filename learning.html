HTML — HyperText Markup Language

Learn how modern web pages are structured using HTML5.

01

Introduction to HTML

HTML is the standard markup language used to create the structure of web pages. It defines elements such as headings, paragraphs, links, images, lists and forms.

02

HTML Document Structure

Learn DOCTYPE, html, head, title and body elements and understand how a complete HTML document is organized.

03

HTML Headings & Paragraphs

Learn heading elements from h1 to h6, paragraph elements, line breaks and basic text formatting.

04

Links & Navigation

Learn anchor tags, relative paths, absolute URLs, navigation menus and links between different pages.

05

Images & Multimedia

Learn how to add images, audio and video to websites using HTML multimedia elements.

06

Lists & Tables

Learn ordered lists, unordered lists, description lists and tables with rows, columns and table headings.

07

HTML Forms

Learn forms, input fields, labels, buttons, radio buttons, checkboxes, select menus and form validation attributes.

08

Semantic HTML

Learn semantic elements such as header, nav, main, section, article, aside and footer to create meaningful page structures.

09

HTML5 Features

Explore modern HTML5 elements, multimedia, semantic structure and useful attributes for modern websites.

01

Introduction to CSS

CSS is used to control the appearance, layout and presentation of HTML elements.

02

03

Selectors

04

Colors & Backgrounds

Learn colors, background images, gradients, opacity and background properties.

05

Box Model

Understand content, padding, border and margin and how they control element spacing.

06

Typography

Learn fonts, font sizes, font weights, text alignment, line height and spacing.

07

Flexbox

Learn display flex, direction, justify-content, align-items, gap, wrapping and flexible layouts.

08

CSS Grid

Learn rows, columns, grid areas, gaps and responsive grid-based page layouts.

09

Responsive Design

Learn media queries and techniques for making websites work properly on mobile, tablet and desktop screens.

10

Transitions & Animations

Learn hover effects, transitions, transforms and CSS animations.

07

09

GROUP BY & HAVING

Learn how to group records and filter grouped results using SQL.

10

Database Design

Learn relationships, normalization and basic techniques for designing efficient relational databases.
